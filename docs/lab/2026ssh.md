# Laboratorio 01 — Conexión remota mediante SSH

## 1. Objetivo

Establecer una conexión remota desde la computadora principal con Windows hacia una laptop antigua con Ubuntu Linux, que utilizaremos como servidor para el proyecto OpsCenter.

## 2. Verificación de conectividad

Primero, conectamos la laptop Linux a la red local mediante un cable Ethernet.

Desde Windows, ejecutamos el comando `ping` para comprobar la comunicación entre ambos equipos:

`ping 192.168.1.26`

**Resultado obtenido:**

```text
Estadísticas de ping para 192.168.1.26:
    Paquetes: enviados = 4, recibidos = 4, perdidos = 0
    (0% perdidos)

Tiempos aproximados de ida y vuelta en milisegundos:
    Mínimo = 1ms, Máximo = 2ms, Media = 1ms
```

Los resultados confirmaron que existía comunicación entre ambos equipos, sin pérdida de paquetes.

## 3. Instalación y verificación de SSH

Después de comprobar la conectividad, instalamos OpenSSH Server en Ubuntu.

Verificamos el estado del servicio y confirmamos que `ssh.socket` se encontraba en estado `active (listening)`, listo para recibir conexiones.

## 4. Conexión remota desde Windows

Desde la terminal de Windows, ejecutamos el siguiente comando:

`ssh cesarl@192.168.1.26`

La conexión se estableció correctamente, permitiéndonos administrar el servidor Linux de forma remota.

Una vez conectados, ejecutamos dos comandos:

- **`hostname`:** muestra el nombre del equipo remoto. En nuestro caso, permitió identificar el servidor como `cesar-server`.
- **`exit`:** finaliza la sesión SSH y regresa a la terminal de Windows mediante el cierre de sesión (*logout*).

## 5. Conclusión

La administración remota de un equipo permite agilizar diferentes procesos, ya que es una opción práctica que ahorra tiempo y evita la necesidad de utilizar varios teclados o ratones.

Además, facilita la administración de servidores cuando no tenemos acceso físico directo a ellos, siempre que exista conectividad de red y los permisos correspondientes.

La conexión SSH se realizó exitosamente, comprobando la comunicación entre Windows y Ubuntu Linux.
